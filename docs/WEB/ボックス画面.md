## 基本情報

| 項目 | 内容 |
|---|---|
| 画面名 | ボックス画面 |
| URL | `/box` |
| 認証要否 | 要 |
| 共通ヘッダー | 要 |
| 共通サイドバー | 要 |

## 画面遷移

| 操作 | 遷移先 |
|---|---|
| ヘッダー押下 | ホーム画面に遷移 |
| 図鑑リンク押下 | 検索画面に遷移 |
| ボックスリンク押下 | ボックス画面に遷移 |
| パーティリンク押下 | パーティ画面に遷移 |
| ログアウトリンク押下 | ログイン画面に遷移 |
| タイプ相性表リンク押下 | タイプ相性表モーダルを表示 |
| 捕まえたポケモンを追加ボタン押下 | 追加画面に遷移 |
| 検索ボタン押下 | 図鑑画面に遷移 |
| 画像ボタン押下 | ボックス詳細画面に遷移 |
| ログアウトリンク押下 | ホーム画面へ遷移 |
| タイプ相性表リンク押下 | タイプ相性表モーダルを表示 |

## 使用API

| 操作 | API |
|---|---|
| 初期表示 | ボックスAPI |
| ポケモン画像ボタン押下 | ボックス詳細API |

## 備考

- 登録した個体数を、ホーム画面に表示する
- 登録したポケモンは、ボックス一覧に表示する
