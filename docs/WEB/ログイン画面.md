# ログイン画面

## レイアウト

![alt text](ログイン画面.png)

## 基本情報

| 項目 | 内容 |
|---|---|
| 画面名 | ログイン画面 |
| URL | `/login` |
| 認証要否 | 不要 |
| 共通ヘッダー | 要 |
| 共通サイドバー | 不要 |

## 画面遷移

| 操作 | 遷移先 |
|---|---|
| ログインボタン押下 | ホーム画面に遷移（ログイン成功時） |
| 新規登録リンク押下 | 新規登録画面に遷移 |
| タイプ相性表リンク押下 | タイプ相性表モーダルを表示 |

## 使用API

| 操作 | API |
|---|---|
| ログインボタン押下 | ログインAPI |

## 備考

- ログイン失敗の場合、※ユーザーIDまたは、パスワードが違いますと表示する
