## 画面遷移

| 操作 | 遷移先 |
|---|---| 
| ヘッダー押下 | ホーム画面に遷移 |
| 図鑑リンク押下 | 検索画面に遷移 |
| ボックスリンク押下 | ボックス画面に遷移 |
| パーティリンク押下 | パーティ画面に遷移 |
| ログアウトリンク押下 | ログイン画面に遷移 |
| タイプ相性表リンク押下 | タイプ相性表モーダルを表示 |
| パーティボタン押下 | パーティ一覧モーダルを表示 |
| 戻るボタン押下 | ボックス画面に遷移 |
| 変更ボタン押下 | ポケモン追加・変更画面に遷移 |
| 削除ボタン押下 | 削除許可モーダルを表示 |
| 削除許可ボタン押下 | ボックス画面に遷移 |
| タイプ弱点ボタン押下 | 弱点モーダルを表示 |

| 操作 | API |
|---|---|

| ボックスリンク押下 | ボックスAPI |
| パーティリンク押下 | パーティAPI |
| ログアウトリンク押下 | ログアウトAPI |
| タイプ相性表リンク押下 | タイプ相性表API |
| パーティボタン押下 | パーティ一覧API |
| 削除許可ボタン押下 | 削除API |
| タイプ弱点ボタン押下 | 弱点API |
