# Pokemon Master 要件定義書

## 1. プロジェクト概要

### 1.1 アプリ名
- 記入：Pokemon Master

### 1.2 開発目的
- このアプリを作る目的：
  - 捕まえたポケモンのデータをまとめるため
  - ポケモン図鑑機能  
- ユーザーに提供したい価値：
  - 捕まえたポケモンの育成状況の把握ができる
  - 捕まえたポケモンの絞り込み検索ができる
  - 捕まえたポケモンのタイプ相性がわかる(攻防)
  - すべてのポケモンを検索できる
  - パーティーを登録できる
- ポートフォリオとして伝えたいこと：
  - すべてのコードをAIを使用せず、自分で考え実装
  - Web,API,DBすべて作成

### 1.3 開発期間
- 開発開始日：2026.9.22
- 開発終了予定日：2026.11.30

### 1.4 開発対象範囲
- 今回の開発で対象にする範囲：
  - Web
  - API
  - DB
- 今回の開発で対象外にする範囲：
  -ポケモン情報（PokemonApiから取得）

---
