# Pokemon Master 要件定義書

## 1. プロジェクト概要

### 1.1 アプリ名
- 記入：Pokemon Master

### 1.2 開発目的
- このアプリを作る目的：
  - 捕まえたポケモンのデータをまとめるため
  - ポケモン図鑑機能  
- ユーザーに提供したい価値：
  - 捕まえたポケモンの把握ができる
  - 捕まえたポケモンの絞り込み検索ができる
  - 捕まえたポケモンのタイプ相性がわかる
  - すべてのポケモンを検索できる
  - パーティーを登録できる
- ポートフォリオとして伝えたいこと：
  - すべてのコードをAIを使用せず、自分で考え実装
  - Web,API,DBすべて作成

### 1.3 開発期間
- 開発開始日：2026.9.22
- 開発終了予定日：2026.11.30

### 1.4 開発対象範囲
- 今回の開発で対象にする範囲：
  - Web
  - API
  - DB
- 今回の開発で対象外にする範囲：
  -ポケモン情報（PokemonApiから取得）

---

## 2. 対象ユーザー

### 2.1 想定ユーザー
- どのような人が利用するか：
  - ポケモンのゲームをプレイしている人

### 2.2 ユーザーの目的
- ユーザーがこのアプリを使って達成したいこと：
  - 捕まえたポケモンの育成状況の把握ができる
  - 捕まえたポケモンのタイプ相性がわかる(攻防)
  - すべてのポケモンを検索できる

### 2.3 利用シーン
- どのような場面で利用するか：
  - 戦闘時
  - 新しいポケモンを捕まえたとき
  - 捕まえたポケモンのレベルが上がったとき
  - 特定のポケモンを捕まえたいとき

---

## 3. 機能の優先順位

### 3.1 Must（必ず実装する機能）
- ポケモン検索
- 絞り込み検索
- 画像
- ポケモンID
- 名前
- 英語名
- 性別
- 分類
- タイプ記載
- 高さ・重さ
- タイプ相性
- 種族値
- パーティー登録・編集

### 3.2 Should（時間があれば実装したい機能）
- 進化の流れ

### 3.3 Could（余裕があれば追加する機能）
- ポケモンの実数値

### 3.4 今回は実装しない機能
- ポケモンの特性
- タマゴグループ
- 努力値
