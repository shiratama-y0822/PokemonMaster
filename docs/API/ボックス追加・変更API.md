# ボックス追加API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | ボックス追加・変更API |
| HTTPメソッド | POST |
| URL | /POST/box |
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| pokemonid | int | o | 図鑑番号 |
| nickname | String | o | ニックネーム |
| gender | int | o | 性別 |
| type | string | o | タイプ |

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
なし

## ステータスコード

| コード | 条件 |
|---|---|
| 201 | 正常終了 |
| 400 | 入力エラー |

## 備考

- 必須項目が未入力の時、選択してくださいと表示する
