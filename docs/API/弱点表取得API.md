# 弱点表取得API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | 弱点表取得API |
| HTTPメソッド | GET |
| URL | /{pokemonId}/weaknesses |
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| pokemonId | int | o | ポケモンを識別するID |

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
| pokemonId | int | ポケモンID |
| attackTypeId | int | 攻撃タイプID |
| multiplier | int | 計算後のダメージ倍率 |

## ステータスコード

| コード | 条件 |
|---|---|
| 200 | 正常終了 |
| 404 | 指定したポケモンが存在しない |
| 500 | サーバー内部エラー |

## 備考

- 弱点は、防御側のステータスを表示する
- 弱点ボタンを押下すると、モーダルで表示する
