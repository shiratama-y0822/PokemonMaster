# ログインAPI

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | ログインAPI |
| HTTPメソッド | POST |
| URL | /login |
| 認証要否 | 不要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| user_id | string(16) | o | ログインに使用するID |
| nickname | string(6) | o | ログインに使用するユーザー名 |
| password | string(64) | o | ログインに使用するパスワード |

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
| username | string | ユーザー名（ヘッダー表示用） |
| JWT | string | setCookieで返却 |

## ステータスコード

| コード | 条件 |
|---|---|
| 200 | ログイン成功 |
| 400 | 入力エラー |
| 401 | 認証失敗 |

## 備考

- アカウント名入力条件
  - 全角英数字
  - 平仮名
  - カタカナ
- 許可しない値：
  - 漢字
  - 記号
- 入力エラーの時、以下が発生する
  - 英数字・平仮名・カタカナのみ入力してください
  - 英数字は半角で入力してください
  - 1~12文字で入力してください
