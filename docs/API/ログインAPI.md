# ログインAPI

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | ログインAPI |
| HTTPメソッド | POST |
| URL | /api/login |
| 認証要否 | 不要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| userId | string | o | ログインに使用するID |
| password | string | o | ログインに使用するパスワード |

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
| nickname | string | ニックネーム（ヘッダー表示用） |
| JWT | string | setCookieで返却 |

## ステータスコード

| コード | 条件 |
|---|---|
| 200 | ログイン成功 |
| 400 | 入力エラー |
| 401 | 認証失敗 |

## 備考

- 入力内容の条件未達成の時、以下が発生する
  - userId入力
    - 英数字@_-のみ入力してください
    - 英数字は半角で入力してください
    - 1~16文字で入力してください
  - パスワード入力時
    - 英数字!?_-のみ入力してください
    - 半角英数記号で入力してください
    - パスワードは、半角英大文字・半角英小文字・半角数字・記号（! ? _ -）をそれぞれ1文字以上使用し、8〜24文字で入力してください。
