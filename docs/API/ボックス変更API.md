# ボックス変更API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | ボックス変更API |
| HTTPメソッド | PATCH |
| URL | /api/boxes/{boxId} |
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| boxId | int | o | 変更対象のボックスに登録ID |

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| pokemonId | int | × | 変更後の図鑑番号 |
| nickname | String | × | 変更後のニックネーム |
| gender | int | × | 変更後の性別 |

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
| boxId | int | ボックスに登録されたデータの識別ID |

## ステータスコード

| コード | 条件 |
|---|---|
| 200 | 正常終了 |
| 400 | 入力エラー |
| 401 | 未ログイン |
| 404 | 指定されたboxIdが存在しない、または自分のボックスではない |
| 500 | サーバー内部エラー |

## 備考

### 更新ルール

- 変更項目を1つ以上指定する。`{}` は400を返す。
- 省略した項目は現在の値を維持する。
- `nickname` に `null`、空文字、空白のみを指定した場合は、変更後のポケモン名を保存する。
- `pokemonId` または `gender` に明示的な `null` を指定した場合は400を返す。
- `pokemonId` は存在する図鑑番号を指定する。`gender` はそのポケモンに指定できる値にする。
- 自分のボックスだけ変更できる。
- 戻るボタン押下時、ボックス詳細画面に戻る
