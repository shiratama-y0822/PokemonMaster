# ボックス変更API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | ボックス変更API |
| HTTPメソッド | PATCH |
| URL | /box-pokemon/{boxId} |
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| boxId | int | o | 変更対象のボックスに登録ID |

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| pokemonId | int | × | 変更後の図鑑番号 |
| nickname | String | × | 変更後のニックネーム |
| gender | int | × | 変更後の性別 |
| type | string | × | 変更後のタイプ |

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
| boxId | int | ボックスに登録されたデータの識別ID |

## ステータスコード

| コード | 条件 |
|---|---|
| 200 | 正常終了 |
| 400 | 入力エラー |
| 401 | 未ログイン |
| 404 | 指定されたboxIdが存在しない |
| 500 | サーバー内部エラー |

## 備考

- 戻るボタン押下時、ボックス詳細画面に戻る
