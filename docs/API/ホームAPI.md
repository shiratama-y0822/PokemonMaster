# ホームAPI

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | ホームAPI |
| HTTPメソッド | GET |
| URL | /home |
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
| PokemonCaught | int | ログインユーザーが捕まえたポケモンの総個体数 |

## ステータスコード

| コード | 条件 |
|---|---|
| 200 | 正常終了 |
| 400 | ユーザー情報誤入力 |

## 備考

- ログイン完了後、すべてのヘッダーにニックネームが発生する
- ホーム画面を開く時、捕まえたポケモンの個体数を表示する
