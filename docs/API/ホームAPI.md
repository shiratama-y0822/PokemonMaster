# ホームAPI

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | ホームAPI |
| HTTPメソッド | GET |
| URL | /api/home |
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|
| nickname | string | ログインユーザーのニックネーム |
| pokemonCaught | long | ログインユーザーボックス登録個体数。未登録なら0 |

## ステータスコード

| コード | 条件 |
|---|---|
| 200 | 正常終了 |
| 401 | 未認証、JWTが無効・期限切れ、または対象ユーザーが存在しない |

## 備考

- ログイン後にホーム画面を開いた時、ニックネームと登録個体数を表示する
- 同じ種類を2匹登録した場合も、2個体として数える
