# パーティ変更API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | パーティ変更API |
| HTTPメソッド | PUT |
| URL | /parties/{partyId}/members/{position} |
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| partyId | int | o | 対象のパーティID |
| position | int | o | 削除対応の順番（1~6） |

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| boxId | int | o | パーティに登録したボックス番号 |

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
| id | int | パーティメンバーの登録データ |
| partyId | int | パーティアイディー |
| partyName | String | パーティ名 |
| members | Array | パーティに登録したポケモン一覧 |
| boxId | int | ボックス登録番号 |
| position | int | パーティの並び順 

## ステータスコード

| コード | 条件 |
|---|---|
| 200 | 正常終了 |
| 404 | 対象のパーティまたはメンバーが存在しない |
| 409 | 指定したポケモンが同じパーティの別の位置に登録済み |
| 500 | エラー |

## 備考

- 既に登録済みのポケモン同士の配置を入れ替えることはできない
- 一度パーティから外す必要がある
