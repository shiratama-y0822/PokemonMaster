# パーティ変更API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | パーティ変更API |
| HTTPメソッド | PUT |
| URL | /api/parties/{partyId}/members/{position} |
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| partyId | int | o | 対象のパーティID |
| position | int | o | 変更する位置（1~6） |

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| boxId | int | o | 変更後の登録したボックス番号(1以上) |

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
| partyId | int | パーティアイディー |
| partyName | String | パーティ名 |
| members | Array | パーティに登録したポケモンの一覧 |
| members[].boxId | int | ボックスの登録番号 |
| members[].position | int | パーティ内の並び順 |
| members[].pokemonName | String | ポケモン名 |
| members[].image | String | 画像のパス。例：`/image/2.png` | 

## ステータスコード

| コード | 条件 |
|---|---|
| 200 | 正常終了 |
| 400 | 不正な位置・boxId |
| 401 | 未認証 |
| 404 | 対象のパーティ・指定位置のメンバー・ボックスが存在しない |
| 409 | 同じboxIdが別の位置に登録済み |
| 500 | サーバーエラー |

## 備考

- 空の位置は変更できない
- 同じ位置に同じ boxId を指定した場合は 200
- 別の位置との直接交換はできない
