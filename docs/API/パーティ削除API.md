# パーティ削除API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | パーティ削除API |
| HTTPメソッド | DELETE |
| URL | /parties/{partyId}/members/{position} |
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| partyId | int | o | 対象パーティID |
| position | int | o | 削除対応の順番（1~6） |

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
なし

## ステータスコード

| コード | 条件 |
|---|---|
| 204 | 削除完了 |
| 404 | 対象のパーティまたはメンバーが存在しない |
| 500 | サーバー内部エラー |

## 備考

- 削除をする時、確認ダイアログを表示する
