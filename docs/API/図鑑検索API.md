# 図鑑検索API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | 図鑑検索API |
| HTTPメソッド | GET |
| URL | /api/pokedex |
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| name | string | x | 部分一致 |
| pokemonId | int | x | 完全一致 |
| typeId | int | x | type1かtype2のor検索 |

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
| pokemonId | int | 図鑑番号 |
| name | String | 日本語名 |
| image | String | ポケモンの画像URL　※例）image/{pokemonId}.png |　


## ステータスコード

| コード | 条件 |
|---|---|
| 200 | 正常終了（条件なしは全件、該当なしは空配列） |
| 400 | 入力エラー |
| 401 | 未認証 |

## 備考

- pokemonId,name,imageはArrayで表示する
- ボックス検索時は、nicknameでも検索可能とする
- 該当なし（200 []）の時、見つかりませんでしたと表示する
- 入力エラー（pokemonId=abcなど、パラメータの型が不正）の時、入力内容を確認してくださいと表示する
