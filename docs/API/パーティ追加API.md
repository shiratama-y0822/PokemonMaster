# パーティ追加API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | パーティ追加API |
| HTTPメソッド | POST |
| URL | /parties/{partyId}/members|
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| partyId | int | o | 対象のパーティID |

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| boxId | int | o | パーティに登録したボックス番号 |

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
| id | int | パーティメンバーの登録データ |
| partyId | int | パーティアイディー |
| partyName | String | パーティ名 |
| members | Array | パーティに登録したポケモン一覧 |
| boxId | int | ボックス登録番号 |
| position | int | パーティの並び順 |

## ステータスコード

| コード | 条件 |
|---|---|
| 201 | 正常終了 |
| 404 | 対象のパーティまたはメンバーが存在しない |
| 500 | エラー |

## 備考

- パーティは６つ作成可能
- ６体まで編成可能
