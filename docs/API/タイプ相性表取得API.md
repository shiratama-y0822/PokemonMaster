# タイプ相性表取得API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | タイプ相性表取得API |
| HTTPメソッド | GET |
| URL | /typeaisyou |
| 認証要否 | 不要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
| attackTypeId | int | 攻撃タイプID |
| defenceTypeId | int | 防御タイプID |
| multiplier | int | ダメージ倍率 |

## ステータスコード

| コード | 条件 |
|---|---|
| 200 | 正常終了 |
| 500 | サーバー内部エラー |

## 備考

- タイプ相性表リンク押下すると、モーダルで表示する
