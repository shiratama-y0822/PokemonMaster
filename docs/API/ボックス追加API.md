# ボックス追加API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | ボックス追加API |
| HTTPメソッド | POST |
| URL | /box-pokemon |
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| pokemonId | int | o | 図鑑番号 |
| nickname | String | × | ニックネーム |
| gender | int | o | 性別 |
| type | string | o | タイプ |

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
| boxId | int | ボックスに登録されたデータを識別 |

## ステータスコード

| コード | 条件 |
|---|---|
| 201 | 正常終了 |
| 400 | 入力エラー |
| 401 | 未ログイン |
| 500 | サーバー内部エラー |

## 備考

- 必須項目が未入力の時、選択してくださいと表示する
