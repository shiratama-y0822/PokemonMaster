# ボックス一覧API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | ボックス一覧API |
| HTTPメソッド | GET |
| URL | /api/boxes |
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| name | string | × | ポケモン名またはnicknameの部分一致 |
| pokemonId | int | × | 図鑑番号の完全一致 |
| typeId | int | × | タイプ1またはタイプ2が一致 |

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
| boxId | Integer | boxに登録したID |
| name | String | ニックネーム優先、未入力ならポケモン名 |
| image | String | ポケモンの画像URL 形式：/image/{pokemonId}.png |

## ステータスコード

| コード | 条件 |
|---|---|
| 200 | 正常終了 |
| 400 | pokemonIdまたはtypeIdの型が不正 |
| 401 | 未認証 |

## 備考

- 未登録時、画像と名前は表示されない
- 検索条件を省略した場合は、ログイン中のユーザーのボックスを全件返す
- ボックスにポケモンを追加した時、画像と名前を一覧に表示する
- レスポンスは配列で、未登録時は[]
- ログイン中のユーザーのデータをboxId昇順で返す
- 複数の検索条件を指定した場合は、すべての条件に一致するデータを返す
- 検索結果がない場合は200と空配列[]を返す
