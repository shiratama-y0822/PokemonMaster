# ボックス一覧API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | ボックス一覧API |
| HTTPメソッド | GET |
| URL | /api/box |
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
| boxId | Integer | boxに登録したID |
| name | String | ニックネーム優先、未入力ならポケモン名 |
| image | String | ポケモンの画像URL 形式：/image/{pokemonId}.png |

## ステータスコード

| コード | 条件 |
|---|---|
| 200 | 正常終了 |
| 401 | 未認証 |

## 備考

- 未登録時、画像と名前は表示されない
- ボックスにポケモンを追加した時、画像と名前を一覧に表示する
- レスポンスは配列で、未登録時は[]
- ログイン中のユーザーのデータをboxId昇順で返す
