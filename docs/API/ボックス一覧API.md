# ボックス一覧API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | ボックス一覧API |
| HTTPメソッド | GET |
| URL | /box |
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
| name | String | 日本語名または、ニックネーム |
| image | String | ポケモンの画像URL |

## ステータスコード

| コード | 条件 |
|---|---|
| 200 | 正常終了 |

## 備考

- ボックスにポケモンを追加した時、画像と名前を一覧に表示する
- 未登録時、画像と名前は常時されない
