# パーティ取得API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | パーティ取得API |
| HTTPメソッド | GET |
| URL | /api/parties |
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|
| partyId | int | パーティID |
| partyName | String | パーティ名 |
| members | Array | パーティに登録したポケモンの一覧 |
| members[].boxId | int | ボックス登録番号 |
| members[].position | int | パーティ内の並び順 |
| members[].pokemonName | String | ポケモン名 |
| members[].image | String | 画像のパス。例：`/image/2.png` |

## ステータスコード

| コード | 条件 |
|---|---|
| 200 | 正常終了 |
| 401 | 未ログイン |
| 500 | サーバー内部のエラー |

## 備考

- パーティがない場合は `[]` を返す。
