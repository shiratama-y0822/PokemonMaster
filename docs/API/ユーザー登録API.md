# ユーザー登録API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | ユーザー登録API |
| HTTPメソッド | POST |
| URL | /register |
| 認証要否 | 不要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| username | string(12) | o | ログインに使用するユーザー名 |
| password | string(64) | o | ログインに使用するパスワード |

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
なし

## ステータスコード

| コード | 条件 |
|---|---|
| 201 | 正常終了 |
| 400 | 入力エラー |

## 備考

- 入力内容の条件未達成の時、以下が発生する
  - アカウント名入力
    - 英数字・平仮名・カタカナのみ入力してください
    - 英数字は全角で入力してください
    - 1~12文字で入力してください
  - パスワード入力時
    - 英数字・記号のみ入力してください
    - 英数字は半角で入力してください
    - 6文字以上で入力してください
