# ユーザー登録API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | ユーザー登録API |
| HTTPメソッド | POST |
| URL | /api/users |
| 認証要否 | 不要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| userId | string(16) | o | ログインに使用するID |
| nickname | string(6) | o | ログイン後に表示するユーザー名 |
| password | string(60) | o | ログインに使用するパスワード |

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
なし

## ステータスコード

| コード | 条件 |
|---|---|
| 201 | 正常終了 |
| 400 | 入力エラー |
| 409 | userId重複 |


## 備考

- 入力内容の条件未達成の時、以下が発生する
  - user_id入力
    - 英数字@_-のみ入力してください
    - 英数字は半角で入力してください
    - 1~16文字で入力してください
  - nickname入力
    - 英数字・平仮名・カタカナのみ入力してください
    - 英数字は全角で入力してください
    - 1~6文字で入力してください
  - パスワード入力時
    - 英数字!?_-のみ入力してください
    - 半角英数記号で入力してください
    - パスワードは、半角英大文字・半角英小文字・半角数字・記号（! ? _ -）をそれぞれ1文字以上使用し、8〜24文字で入力してください。
