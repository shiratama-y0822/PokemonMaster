# 図鑑検索結果API

## 基本情報

| 項目 | 内容 |
|---|---|
| API名称 | 図鑑検索結果API |
| HTTPメソッド | GET |
| URL | /zukan |
| 認証要否 | 要 |

## リクエスト

### パスパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

### クエリパラメータ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
| name | string | x | 部分一致 |
| pokemonId | int | x | 完全一致 |
| type | string | x | 最大2種類、AND検索 |

### リクエストボディ

| 英名 | 型 | 必須 | 備考 |
|---|---|---|---|
なし

## レスポンス

| 英名 | 型 | 備考 |
|---|---|---|---|
| pookemonId | int | 図鑑番号 |
| name | string | 日本語名 |
| image | String | ポケモンの画像URL |

## ステータスコード

| コード | 条件 |
|---|---|
| 200 | 正常終了 |
| 400 | 入力エラー |

## 備考

- 検索後、該当ポケモンの名前・画像が一覧で表示される
- 入力エラーの時、見つかりませんでしたと表示する
