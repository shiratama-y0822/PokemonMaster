# DB設計書

## ユーザーテーブル

### 基本情報

| 項目 | 内容 |
|---|---|
| テーブル英名 | users |
| テーブル和名 | ユーザー |
| 備考 | ユーザーのアカウント情報を管理する |

### カラム情報

| 英名 | 和名 | 型 | 必須 | PK/FK | 備考 |
|---|---|---|---|---|---|
| user_id | ユーザーID | varchar（16） | o | PK | 重複を許可しない |
| nickname | ニックネーム | varchar（6） | o |  | 重複は許可する |
| password | パスワード | varchar(60) | o |  | ハッシュ化した値を保存 |
