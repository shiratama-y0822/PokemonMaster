# DB設計書

## パーティメンバーテーブル

### 基本情報

| 項目 | 内容 |
|---|---|
| テーブル英名 | party_member |
| テーブル和名 | パーティメンバー |
| 備考 | パーティーにどのボックス内のポケモンが所属するか管理する |

### カラム情報

| 英名 | 和名 | 型 | 必須 | PK/FK | 備考 |
|---|---|---|---|---|---|
| id | アイディー | int | o | PK | パーティメンバーの登録データ |
| partyId | パーティアイディー | int | o | FK | パーティを識別 |
| boxId | ボックス登録番号 | int | o | FK | ボックス登録データを識別 |
| position | ポジション | int | o |  | 1~6の並び順 |
