# DB設計書

## ユーザーテーブル

### 基本情報

| 項目 | 内容 |
|---|---|
| テーブル英名 | users |
| テーブル和名 | ユーザー |
| 備考 | ユーザーのアカウント情報を管理する |

### カラム情報

| 英名 | 和名 | 型 | 必須 | PK/FK | 備考 |
|---|---|---|---|---|---|
| userId | ユーザーアイディー | int | o | PK | 重複を許可しない |
| username | ユーザーネーム | varchar（12） | o | PK | 重複を許可しない |
| password | パスワード | varchar(64) | o | FK |  |
