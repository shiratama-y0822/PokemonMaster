# DB設計書

## パスワードテーブル

### 基本情報

| 項目 | 内容 |
|---|---|
| テーブル英名 | password |
| テーブル和名 | パスワード |
| 備考 | ユーザーが設定したパスワードを管理する |

### カラム情報

| 英名 | 和名 | 型 | 必須 | PK/FK | 備考 |
|---|---|---|---|---|---|
| userId | ユーザーアイディー | int | o | FK | 重複を許可しない |
| password | パスワード | varchar(64) | o |  | ハッシュ化した値を保存 |
